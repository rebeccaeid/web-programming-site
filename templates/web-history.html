Introduction

The World Wide Web (WWW) is an information space built on top of the physical infrastructure of the Internet. While the Internet provides the underlying network of connected computers and packet-routing protocols, the World Wide Web provides a system of interlinked hypertext documents accessed via URLs, HTTP, and HTML.

Milestones in World Wide Web Development

1989: The Web Proposal

Tim Berners-Lee published his initial proposal at CERN for an interconnected hypertext information management system.

Source: W3C Proposal Archive

1990: Joint Proposal (Berners-Lee / Cailliau)

Berners-Lee and Robert Cailliau produced a formal joint proposal, "WorldWideWeb: Proposal for a HyperText Project," describing a web of hypertext documents viewed by browsers.

Source: W3C Proposal Archive

1990: Foundation Technologies (HTML, HTTP, URL)

Berners-Lee authored HTML, HTTP, and URLs, and wrote the first web server (httpd) and web browser (WorldWideWeb) on a NeXT computer.

Source: W3C Historical Documents

1991: Public Launch

Berners-Lee announced the World Wide Web project on the alt.hypertext Usenet group, inviting public collaboration.

Source: CERN Web History

1993: Public Domain Release

CERN placed the core Web software components into the public domain royalty-free, driving immediate worldwide adoption.

Source: CERN Licensing

1993: NCSA Mosaic Browser

Marc Andreessen and Eric Bina released NCSA Mosaic, introducing inline images and intuitive graphical web browsing.

Source: NCSA Historical Archives

1994: Foundation of W3C

Tim Berners-Lee established the World Wide Web Consortium (W3C) to define open, non-proprietary Web standards.

Source: W3C Archives

1995: SSL Encryption for E-Commerce

Netscape released SSL 2.0 to secure HTTP transactions, establishing encrypted web sessions necessary for early e-commerce.

Source: SSL Store (SSL/TLS History)

1996: BackRub / Stanford Research

Larry Page and Sergey Brin, then Stanford researchers, began developing BackRub, a search project analyzing the web's link graph to measure page importance.

Source: Engineering and Technology History Wiki

1998: Search and PageRank (Google)

Larry Page and Sergey Brin incorporated Google, launching a search engine powered by PageRank link-graph analysis.

Source: Google Official History

Mid-2000s: Dynamic Web / Web 2.0

Refinements like AJAX allowed browsers to exchange data with servers in the background, fueling the shift toward interactive Web applications and user-generated content known as "Web 2.0."

Source: W3C Standards

2014: Open Standards and HTML5 Recommendation

The W3C published the HTML5 Recommendation specification, adding native multimedia elements and reducing dependence on proprietary plugins.

Source: W3C Technical Reports

2015: HTTP/2 Protocol Standardized

The IETF standardized HTTP/2 (RFC 7540), introducing multiplexed connections and header compression to improve the efficiency of HTTP communication.

Source: IETF RFC Editor

2019: WebAssembly Core Specification

The W3C published the WebAssembly Core Specification as a Recommendation, establishing a safe, portable, low-level code format designed for efficient execution in Web browsers and other environments.

Source: W3C Technical Reports

2020s–Present: Modern Web Application Architectures

Web development has increasingly incorporated technologies such as edge computing, server-side rendering, client-side hydration, progressive web applications (PWAs), and component-based application architectures. Web applications have also increasingly incorporated AI-powered features such as conversational interfaces, content generation, and intelligent search.

Source: W3C Web Standards
